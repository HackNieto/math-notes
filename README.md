# Notas matemáticas

Herramientas interactivas para entender de forma interactiva la resolución de problemas matemáticos paso a paso.

Úsalo en línea: https://hacknieto.github.io/math-notes/

## Usarlo sin internet

1. Pulsa el botón verde **Code** y luego **Download ZIP**.
2. Descomprime el archivo.
3. Abre `index.html` con cualquier navegador.

Conserva la carpeta completa: si copias un archivo HTML suelto, se verá sin estilos porque los busca en la carpeta `css`.
